# AI agenti – napojení na GitHub

Návod, jak v AI agentovi nastavit přístup ke konkrétnímu GitHub repozitáři,
aby v něm mohl pracovat a dělat změny. Ukázáno na třech agentech:

1. **Claude Code (v cloudu, claude.ai/code)** – Anthropic
2. **GitHub Copilot – cloud agent** – GitHub
3. **Gemini CLI jako GitHub Action (`run-gemini-cli`)** – Google

Odevzdávané soubory:

- `AI_agenti_napojeni_na_GitHub.pdf` – návod se screenshoty
- `Zdroje.pdf` – seznam použitých zdrojů
- `podklady/` – zdrojové HTML obou PDF (`navod.html`, `zdroje.html`, `styl.css`)
  a všechny použité screenshoty (`podklady/img/`)

PDF se generují z HTML tiskem v Chromiu (Playwright, `page.pdf`, formát A4).
